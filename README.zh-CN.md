# QGIS-AI-Mapper

[English](README.md) | [简体中文](README.zh-CN.md)

**用自然语言描述需求，在QGIS中完成地图制作。**

QGIS-AI-Mapper是运行于QGIS桌面的对话式智能制图插件。你可以提出问题、调整某个图层，也可以直接描述一幅完整地图。插件结合当前工程中的图层和字段理解请求，执行数据加载、空间处理、样式设置和打印布局操作。结果直接呈现在QGIS中，生成的图层和布局可以继续查看、编辑和保存。

|使用方式|适合的需求|
|---|---|
|简单聊天|解释概念、回答问题、讨论制图思路|
|单步骤操作|加载边界、调整河流颜色、生成缓冲区、修改地图标题|
|多步骤复合制图|通过一条请求组合数据获取、空间处理、样式设置和布局导出|

## 一、安装与准备

### 运行环境

使用配备**Qt5／PyQt5的QGIS3.36**。参考安装环境为Windows、QGIS3.36.1和Python3.9.18。插件在QGIS内部运行，使用其提供的PyQGIS、Processing、GDAL和Qt运行库。

还需要个人**千问APIKey**、可访问千问服务的网络，以及[requirements.txt](requirements.txt)列出的Python依赖。文本理解与任务规划使用`qwen-plus`，样式参考检索使用`text-embedding-v4`。请在千问账号中开通相应模型权限，并准备可用的服务额度。1.0.0版本使用文字输入，语音输入尚未启用。

### 安装步骤

1. 从[发布页面](https://github.com/ChanfHo/QGIS_AI_Plugin/releases/tag/v1.0.0)下载**`qgis_ai-1.0.0.zip`**和**`requirements.txt`**，选择发布附件中的插件ZIP。
2. 打开**QGIS安装附带的OSGeo4W Shell**，进入下载的依赖文件所在目录，安装并检查依赖：

   ```bash
   python -m pip install -r requirements.txt
   python -c "import openai, httpx, langgraph, langchain_core, requests, numpy, psycopg2; print('Dependencies OK')"
   ```

   依赖需要安装到QGIS使用的Python环境。[安装指南](SETUP.md#中文)还介绍了QGIS专用Python启动器和手动源码安装方法。
3. 启动QGIS，打开**插件→管理并安装插件→从ZIP安装**，选择插件ZIP，安装后启用**QGIS-AI-Mapper**。
4. 在配置窗口输入个人千问APIKey并完成验证，通过工具栏图标或插件菜单打开面板。

配置窗口提供掩码输入、显示／隐藏、验证、保存、更换和清除功能。验证成功后即可使用对话和任务入口。每次加载插件会建立新的Key验证会话；同一次加载期间，发送消息、开始新任务和重新打开面板均复用已验证的Key。Windows下可通过DPAPI保护本地保存的Key。面板中的**配置／更换APIKey**按钮可再次打开配置窗口。

### 数据和语言

可以使用已有QGIS工程中的数据，也可以通过随包的**公共只读连接**请求行政区划及行政中心、道路、水系、地形索引和样式参考资源。地形文件经HTTP下载。读取远程数据后，可在本地完成分析和制图，无需登录服务器。连接与自建服务说明见[数据访问文档](DATABASE_ACCESS.md#中文)。

在面板或Key配置窗口中选择**跟随QGIS／中文／English**。也可以明确提出回答语言，例如“请用英文回答”。英文请求中的真实中文图层名、字段名和路径继续保持原样，与QGIS工程一致。

## 二、在对话面板中工作

### 简单聊天

面板可以用于概念解释和简短问答。普通聊天请求会得到文字回答，例如：

```text
你好，请简单介绍一下你自己。
解释一下普通地图和专题地图的区别，只做说明，不修改当前工程。
河流地图配色需要考虑哪些因素？请只解释。
```

希望获得解释时，说明需要讨论的问题；希望修改工程时，明确写出操作和目标对象。

### 单步骤任务与局部调整

单步骤请求适合逐步构建地图，也适合修改已有成果。以下每一行都可以作为独立请求发送：

```text
加载广西壮族自治区省界，图层命名为“广西壮族自治区省界”。
将“示例河流”的线条设置为蓝色，线宽设为0.6毫米。
为“示例河流”生成100米缓冲区，结果命名为“河流缓冲区”。
将“湖北省高速公路”裁剪到“武汉市”边界范围，结果命名为“武汉市高速公路”。
将“武汉市高速公路”重投影到EPSG:4547。
将“河流缓冲分析图”布局的标题改为“河流周边影响范围”。
```

针对已有数据，直接使用图层面板显示的名称。分级设色、分类渲染和标注需要写出实际字段名。缓冲分析应选用适合研究区域、单位为米的投影坐标系。工程包含多个布局时，说明需要修改的布局名称。

每条消息都会结合当前工程和图层重新理解。与“把它改深一点”相比，“将‘示例河流’改为深蓝色”提供了明确的操作目标。普通聊天消息不会形成持久的对话记忆，请在每条请求中写明完成任务需要的上下文。

### 多步骤复合任务

复合请求可以同时描述目标成果及其操作要求。插件会展示计划，按顺序执行各个步骤，并将前面生成的结果用于后续操作。数据加载、裁剪、样式设置和布局创建可以写在同一条消息中。

|能力|可以提出的要求|
|---|---|
|数据获取|加载本地矢量、栅格文件；读取公共行政区划、道路、水系及地形资源|
|空间处理|执行QGISProcessing中的裁剪、缓冲、重投影等操作|
|地图表达|设置符号和线面样式、分类与分级渲染、标注及栅格样式|
|布局整饰|创建页面、地图、标题、图例、比例尺和指北针，调整地图范围|
|成果导出|通过保存窗口将打印布局导出为PNG|

执行过程中可查看计划和步骤进度，完成后查看总结。生成的图层和打印布局都是普通QGIS对象，可以继续使用QGIS工具编辑。

## 三、完整使用示例

### 示例A：本地河流缓冲分析图

下载仓库提供的[合成河流线数据](examples/local_river.geojson)，拖入QGIS，将图层重命名为**示例河流**。数据使用EPSG:3857坐标系，单位为米，适合熟悉操作过程。

将以下内容作为一条消息发送：

```text
为“示例河流”生成100米缓冲区，结果命名为“河流缓冲区”。
将“河流缓冲区”设置为浅蓝色填充、蓝色边界。
将“示例河流”设置为深蓝色线条，线宽为0.6毫米。
缩放到“河流缓冲区”的范围。
创建A4横向打印布局，标题为“河流缓冲分析图”。
添加图例、比例尺和指北针，然后将布局导出为PNG。
```

任务依次完成空间分析、两个图层的样式设置、视图调整、布局创建和导出。出现图例选择窗口时勾选需要显示的条目，出现保存窗口时选择PNG存放位置。工程中会保留原始河流、缓冲区，以及名为**河流缓冲分析图**的打印布局。

随后可用单步骤任务继续调整：

```text
将“河流缓冲区”的填充改为浅黄色，边界改为橙色。
```

也可以在QGIS中调整符号或移动布局元素。合成线数据用于练习操作，不代表真实河流测量成果。

### 示例B：区域普通地图

将公共数据读取和完整布局制作组合起来。在新工程中输入：

```text
制作一幅广西壮族自治区普通地图。
加载广西壮族自治区省界、地级市边界、地级市行政中心和线状水系。
采用浅色背景、细灰色行政边界和蓝色河流。
使用名称字段标注地级市行政中心。
将地图范围调整到广西壮族自治区。
创建A4横向布局，标题为“广西壮族自治区普通地图”，
添加图例、比例尺和指北针，并导出为PNG。
```

插件会拆分不同数据的获取步骤，加载图层，设置样式和标注，再创建布局。行政区名称保持与公共数据一致。图例窗口中可以选择最终显示的图层和分类条目。导出后保存QGIS工程，即可保留图层、符号和布局，继续修改地图。

### 示例C：使用自己的数据制作专题地图

先加载面数据，并确认需要表达的数值字段。请求中说明图层名、字段名、分级方法、分级数量、色带和布局标题。

对于名为**区县统计**、具有数值字段**population**的图层，可发送：

```text
使用“区县统计”图层的population字段制作人口专题地图。
采用分位数法划分为5级，使用从浅橙色到深橙色的色带，
面要素之间使用细白色边界。
缩放到“区县统计”的范围，创建A4纵向布局，标题为“区县人口分布图”。
添加图例、比例尺和指北针，并导出为PNG。
```

示例使用数据中已有的统计值。制作其他指标的地图时，在请求中写出对应的实际字段和标题即可。

### 怎样把需求说清楚

将**目标对象、操作要求和输出结果**一起说明。加载数据时写出文件路径或行政区域；空间处理时说明输入图层、范围和距离单位；样式设置时明确图层、字段和视觉效果；布局时说明纸张、方向、标题及导出格式。

例如，“将‘湖北省高速公路’裁剪到‘武汉市’范围，结果命名为‘武汉市高速公路’”同时说明了输入、处理范围和输出名称。完整制图请求可以先说明主题，再补充数据、样式和版面要求。

## 四、操作、恢复与帮助

### 常用操作

|控件或按键|用途|
|---|---|
|Enter／发送|提交当前消息|
|Shift+Enter|换行，编写较长请求|
|思考区域|展开或收起解释内容|
|步骤进度|查看当前步骤和已完成步骤|
|停止|停止后续执行，保留已经完成的工程修改|
|Key配置|验证、更换或清除当前Key|
|语言选择|选择中文、英文或跟随QGIS|

正在进行的模型或网络请求可能需要返回后才能停止。需要保留的地图成果请保存为QGIS工程。

### 修正失败步骤并继续

错误卡片会说明出错步骤，并提供相应恢复操作。图层、字段、路径或参数需要修正时，在输入框补充正确信息后继续；临时连接问题可使用重试。当前任务会保留已完成步骤。

例如，缓冲步骤未找到道路图层时，先在QGIS核对名称，再回复：

```text
继续当前步骤，输入图层使用“湖北省高速公路”，
距离为100米，结果命名为“公路缓冲区”。
```

需要替换等待恢复的任务时，可使用错误卡片的新任务操作，或以**“新任务：”**开头发送请求。恢复状态保存在当前插件进程中；重启QGIS后，从保存的工程开始新任务。

### 常见问题

|情况|处理方式|
|---|---|
|缺少Python模块|在QGIS的Python环境安装依赖，然后重启QGIS|
|Key验证失败|检查Key、服务额度、模型权限和网络|
|聊天可用但样式检索失败|检查`text-embedding-v4`权限|
|远程数据加载失败|检查网络及数据服务，或加载本地数据|
|找不到图层或字段|使用QGIS显示的实际名称|
|缓冲距离不符合预期|检查数据坐标系和算法单位|
|重新加载后出现Key窗口|为新的插件会话完成验证|
|语音按钮不可用|1.0.0版本使用文字输入|
