# QGIS-AI-Mapper 1.0.0

## English

Released on October 26, 2026. [Download the plugin](https://github.com/ChanfHo/QGIS_AI_Plugin/releases/tag/v1.0.0).

The first public version supports simple chat, individual GIS operations and compound mapping requests in Chinese and English. It loads data, runs spatial processing, applies layer styles and labels, creates print layouts and exports PNG maps. The panel includes personal Qwen Key verification, task progress, stopping and recovery for supported failures. A dedicated public read-only connection provides remote data and style references.

The reference environment is Windows, QGIS 3.36.1, Python 3.9.18 and Qt5/PyQt5. The plugin uses text input in this version. Install dependencies into QGIS's Python environment, install `qgis_ai-1.0.0.zip` through Plugin Manager, and verify your Key. See [installation](SETUP.md) and the [user manual](README.md).
