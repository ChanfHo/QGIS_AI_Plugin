# QGIS AI Mapper

QGIS AI Mapper 是一个运行在 QGIS 3.x 中的 Python 插件。它把自然语言交互与 QGIS 地理信息处理结合起来，帮助用户用更直观的方式咨询 QGIS、分析当前工程，并执行部分 GIS 操作。

## 项目能做什么

- 在 QGIS 中提供 AI 对话面板，并通过菜单和工具栏入口打开。
- 根据用户请求判断任务类型，规划处理步骤，并将任务分派给不同的智能体。
- 结合当前 QGIS 工程中的图层信息（图层名称、类型和属性字段）生成更有针对性的处理请求。
- 使用 LangGraph 组织“任务规划—路由—智能体执行—结果更新”的工作流。
- 支持数据获取、空间处理、样式管理、布局操作等扩展方向，并保留相应的模型、知识库和脚本目录。

## 目录说明

| 路径 | 作用 |
| --- | --- |
| `qgis_ai.py` | QGIS 插件入口，负责菜单、工具栏和停靠面板的生命周期。 |
| `qgis_ai_dockwidget.py` | AI 对话停靠窗口。 |
| `chat_model.py` | 模型调用、响应解析和用户意图识别。 |
| `workflow_graph.py` | 基于 LangGraph 的任务规划、路由与执行流程。 |
| `agents.py` | 各类 GIS 智能体的具体执行逻辑。 |
| `prompts.py`、`agent_prompts.py` | 任务规划、路由和智能体使用的提示词。 |
| `knowledge_base/` | 项目知识库及相关检索资源。 |
| `model/` | 模型或模型调用相关资源。 |
| `scripts/`、`test/` | 辅助脚本与测试代码。 |
| `metadata.txt` | QGIS 识别插件所需的元数据文件。 |

## 在 QGIS 中安装

1. 将整个项目目录放入本地插件目录，或在 QGIS 的插件搜索路径中添加项目根目录。
2. 项目根目录必须是包含 `metadata.txt` 和 `__init__.py` 的目录。
3. 重启 QGIS，打开“插件 → 管理和安装插件”，搜索并启用“QGIS AI Mapper”。
4. 启用后，可通过插件菜单或工具栏图标打开 AI 对话面板。

本项目当前使用的本地开发目录示例：

```text
D:\Master\QGIS_AI_Plugin\qgis_ai_private
```

## 运行依赖与配置

插件依赖 QGIS 提供的 PyQGIS、Qt 环境，以及项目代码中使用的 Python 第三方库。模型调用还需要配置可用的模型服务、应用信息和网络环境。首次运行前，请根据本地环境检查 `chat_model.py`、`agents.py` 和相关脚本中的依赖是否已经安装并可访问。

## 工作流概览

用户输入请求后，插件通常按以下顺序处理：

1. 读取用户请求和当前工程图层信息；
2. 由任务规划节点拆解目标并生成步骤；
3. 由任务路由节点选择合适的智能体；
4. 由智能体执行数据、空间、样式或布局相关操作；
5. 更新执行状态，并向用户返回结果或错误信息。

## 开发与测试建议

- 修改前先确认 QGIS 版本、Python 环境和第三方依赖一致。
- 修改插件后，在 QGIS 中重新加载插件或重启 QGIS 以验证实际效果。
- 使用项目中的测试目录和脚本进行针对性检查。
- 不要将 API 密钥、应用密钥或其他敏感配置提交到公开仓库。

## 项目状态

这是一个持续迭代中的 QGIS AI 插件项目。当前代码重点探索 LangGraph 工作流、QGIS 图层上下文、自然语言 GIS 操作和样式/布局辅助能力。具体功能是否可用，取决于本地 QGIS 环境、依赖安装情况和模型服务配置。
